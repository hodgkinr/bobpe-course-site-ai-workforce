Week 2 Applied Judgment Quiz

Learning objectives: Turn a workplace need into a clear request with goal, audience, context, constraints, and a useful output format; then improve the request through iteration.; Choose what information is appropriate to share, account for privacy, fairness, accessibility, and policy, and retain human accountability.

Week 2: Define the task and provide context

Scenario-based practice on task briefs, safe context, and usable output formats.

Question 1. A coworker's request says, “Make this better.” They need a reminder for first-time visitors to a fictional event. What is the best way to improve the task statement?
A concrete goal, audience, relevant context, constraints, and output shape make the request actionable and reviewable.
Question 2. A fictional event reminder needs a draft. Which prompt has the clearest goal and output shape?
A clear prompt names the action and asks for a format suited to the next step.
Question 3. A worker wants to summarize a real client message and considers pasting the client's name, phone number, and account number. What is the best choice for practice?
Use an invented or approved safe example; do not share sensitive client information with a generic service.
Question 4. A fictional open-house notice needs four facts. Which context should go into a practice prompt?
Provide only the relevant invented event facts; unrelated personal or workplace details add risk without helping the task.
Question 5. A worker wants a generated summary of six fictional event comments to avoid claiming that a small sample represents everyone. Which output format is most useful?
A table that ties each theme to comment IDs and notes exceptions keeps evidence visible and limits overgeneralization.
Question 6. A worker asked for a message under 80 words, but the generated version is 112 words and includes all four facts. What should happen next?
The output missed a checkable constraint, so revise with a targeted direction and review the new version for both length and factual accuracy.
Question 7. A draft request asks for a friendly public reminder but gives no length limit, required facts, or format. What is the most useful addition?
Add checkable boundaries and a format that make the result useful and easy to inspect.
Question 8. An AI-drafted notice contains a new street address that was not in the fictional event facts. What should the reviewer do?
The address is unsupported; remove it or verify it with an authoritative event source before use.
Question 9. The first AI draft added a registration requirement that the fictional facts did not mention. Which follow-up best diagnoses and addresses the issue?
A targeted follow-up names the unsupported addition, restates the allowed source facts, and gives a safe way to handle unknowns.
Question 10. A prompt asks AI to produce a “final approved” policy summary from a short fictional excerpt. Which framing is more appropriate?
AI can draft a summary for human review, but a prompt cannot confer approval or authority; the summary must be compared with the source and approved by the responsible person.
